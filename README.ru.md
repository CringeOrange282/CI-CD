# CI-CD

[English version](README.md)

## Запуск Orchestra

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --target orchestra
./build/bin/debug/orchestra
```

По умолчанию Orchestra принимает запросы на `127.0.0.1:8080`. Чтобы изменить
адрес и порт, задайте `ORCHESTRA_HOST` и `ORCHESTRA_PORT`. Базовый URL сервиса
данных задаётся через `ORCHESTRA_DATA_URL`. Значение по умолчанию —
`http://127.0.0.1:8081`. Сервис данных должен принимать запросы
`GET /information` с параметрами `information_id` и `information_from_date`.
Если данные найдены, он возвращает `200` и данные в формате JSON. Если данных
нет, он возвращает `404`.

## Отправка запроса на обработку

```sh
curl http://127.0.0.1:8080/requests \
  -H 'Content-Type: application/json' \
  -d '{"user":"alice","operation":"operation_type1","information_id":"example","information_from_date":"2026-11-24"}'
```

Все четыре поля должны быть непустыми строками. Запросы с одинаковыми
`operation`, `information_id` и `information_from_date` получают один
идентификатор операции, даже если их отправили разные пользователи.
Пока операция ожидает результата, сервис возвращает `202` с её идентификатором.
После завершения сервис возвращает `200` с результатом из кеша.

Если данные отсутствуют, сервис возвращает `404`. Если HTTP-клиент сообщает
о тайм-ауте, сервис возвращает `504`. При других сбоях обращения к сервису
данных возвращается `502`. Статус операции и результат можно получить
запросом `GET /operations/<operation_id>`.

## API обработчика

1. Вызовите `POST /queue/next`, чтобы получить следующее задание. Сервис
   возвращает `200` с полями `operation_id`, `operation` и `process_data`.
   Если очередь пуста, сервис возвращает `204`. В поле `process_data`
   передаётся JSON от сервиса данных. Пока результат обработки не отправлен,
   повторные запросы возвращают то же задание.
2. Отправьте `{"result": ...}` запросом `PUT /operations/<operation_id>/result`.
   Сервис сохранит результат в кеше, после чего станет доступно следующее
   задание из очереди. Повторная отправка того же результата завершится
   успешно. Попытка отправить другой результат для завершённой операции
   вернёт `409`.

API выдаёт по одному заданию на обработку. Очередь и кеш результатов хранятся
в памяти и очищаются при перезапуске Orchestra. HTTP API работает без
аутентификации.
